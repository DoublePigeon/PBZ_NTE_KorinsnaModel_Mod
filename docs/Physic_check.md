在UE5游戏模组制作中，将男性主角替换为穿裙子的女性角色，并且使用IK Retargeter（IK重定向）时，遇到裙子穿模和原游戏物理导致裙子乱飞是非常经典的问题。

原游戏的物理会让裙子乱飞，通常是因为原游戏的全局风力系统、重力设置或世界坐标下的移动速度过快导致的。

为了实现**“裙子只与自身碰撞（腿、臀部），不与世界环境（风、水、其他NPC）交互，且基于骨骼运算”，最佳的解决方案是为你的替换模型创建一个专属的后处理动画蓝图（Post Process Anim Blueprint）**，并在其中进行局部的物理结算。

方案二：使用 Kawaii Physics 插件

如果你有办法在打包Mod时附带插件（或者该游戏本身就已经集成了Kawaii Physics），这绝对是最优解。Kawaii Physics 是专门为二次元裙子、头发开发的节点，天生免疫各种乱飞问题。

实施步骤：

    获取并启用 Kawaii Physics 插件。

    同样创建一个 后处理动画蓝图 (Post Process AnimBP)。

    添加 Kawaii Physics 节点（裙子有几根主骨骼链，就加几个节点，通常连成一串）。

    为什么它好用？

        它默认就是在**局部空间（Local Space）**计算的，绝不会因为角色瞬间移动或原游戏的奇怪重力而乱飞。

        自带碰撞体： 你不需要去调教麻烦的UE物理资产（PhAT）。直接在 Kawaii Physics 节点内部，添加球形碰撞体（Spherical Limits）或胶囊体，将它们绑定到大腿（Thigh）骨骼上，调整大小包裹住腿即可。

        它不与游戏引擎的全局物理产生任何瓜葛，完全独立、丝滑。

使用 Kawaii Physics 是解决二次元角色（特别是动作Mod替换）裙子和头发物理的最佳方案。它的底层逻辑是“基于骨骼的轻量级伪物理”，完全不依赖UE自带的物理资产（PhAT），默认在局部空间结算，因此完美隔绝了游戏世界里的风力和重力乱飞现象。

以下是保姆级的详细操作指南，分为插件准备、基础配置、头发物理和裙子防穿模物理四个阶段。
第一阶段：准备工作

    获取与安装插件

        去 GitHub 搜索 KawaiiPhysics（作者是 pafuhana1213）。

        下载对应你UE5版本的插件包。

        在你的UE工程目录下新建一个 Plugins 文件夹，将下载解压后的 KawaiiPhysics 文件夹丢进去。

        重启工程，在 Edit -> Plugins 中搜索 Kawaii，确保其已启用。

    创建后处理动画蓝图 (Post Process AnimBP)

        在内容浏览器找到你的女性模型（Skeletal Mesh）。

        右键模型 -> Create -> Anim Blueprint。

        打开女性模型网格体面板，在细节面板搜索 Post Process，将 Post Process Anim Blueprint 指定为你刚创建的蓝图。

        注：后处理蓝图会在IK重定向和所有常规动画播放完之后，最后执行物理运算，这是Mod制作的关键。

第二阶段：为头发赋予物理（以马尾为例）

头发的碰撞相对简单，主要是防止穿透头部和后背。

    打开你刚才创建的后处理动画蓝图。

    在 AnimGraph 中，右键搜索并添加 Kawaii Physics 节点。

    将输入的 Pose 连入 Kawaii 节点，再连到 Output Pose。

    设置物理参数（选中 Kawaii 节点，看右侧细节面板）：

        Root Bone（根骨骼）: 选择你马尾的第一根骨骼（例如 Hair_Ponytail_01）。插件会自动顺藤摸瓜，给这根骨骼下面的所有子骨骼加上物理。

        Damping（阻尼）: 控制头发的空气阻力。值越大，头发越像在水里，飘动越迟缓。（推荐：0.1 - 0.2）

        Stiffness（刚度）: 控制头发恢复原状的能力。值越大，头发越硬。（推荐：0.05 - 0.1）

        Radius（骨骼碰撞半径）: 这代表头发本身的粗细，稍微给一点（例如 2.0 - 5.0），防止头发太细卡进模型里。

    设置防穿模碰撞体（Collision Limits）：

        头发不能穿进脑袋。在 Kawaii 节点的细节面板找到 Spherical Limits（球形限制）。

        点击 + 号添加一个元素。

        展开它，Driving Bone（驱动骨骼） 选择 Head（头部骨骼）。

        勾选蓝图上方的 Show Debug 眼睛图标，并在视口中点击运行/编译。

        你会在头部看到一个半透明的球体。调节 Radius（半径） 和 Offset（偏移），让这个球体完美包裹住角色的后脑勺和脖子。

        原理：当马尾骨骼碰到这个球时，就会滑开，绝对不会穿模。

第三阶段：为裙子赋予物理（重头戏）

裙子比头发复杂，因为裙子通常由一圈骨骼组成（前、后、左、右各有几条骨骼链），而且男主大步奔跑的动作极易让大腿穿破裙子。
1. 串联多个 Kawaii Physics 节点

如果你的裙子没有一个总的“Skirt_Root”骨骼（通常都没有），你需要为每一条裙子骨骼链添加一个 Kawaii 节点。

    依次添加 Kawaii 节点，串成一条线：Input Pose -> Kawaii(左前裙) -> Kawaii(右前裙) -> Kawaii(左后裙) -> Kawaii(右后裙) -> Output Pose。

    分别把它们的 Root Bone 设置为对应裙摆链的第一根骨骼。

    裙子的 Stiffness（刚度）建议比头发稍微大一点（例如 0.2），让裙子有垂坠感，不会轻易飘得太高。

2. 设置腿部与骨盆的碰撞体（核心防穿模技术）

因为有多个 Kawaii 节点，如果在每个节点里都手动建一次大腿碰撞体，不仅麻烦而且极其耗费性能。正确做法是使用蓝图变量统一定义碰撞体。

步骤：

    在 AnimBP 的左侧 Variables（变量）面板，新建一个变量，命名为 LegColliders。

    将变量类型设置为 Kawaii Physics Capsule Limit（胶囊体限制），并将其右侧的图标点成网格状，将其变为 Array（数组）。

    编译蓝图。

    选中 LegColliders 变量，在右侧的 Default Value（默认值）里，点击 + 号添加 3 个元素：

        元素 0 (左腿): Driving Bone 设为 Thigh_L（左大腿骨骼）。调整半径（Radius）和长度（Length），使其包裹左大腿。

        元素 1 (右腿): Driving Bone 设为 Thigh_R（右大腿骨骼）。同样包裹右大腿。

        元素 2 (骨盆/臀部): Driving Bone 设为 Pelvis（骨盆骨骼）。包裹住臀部，防止裙子从上面陷进去。

    如何包裹得严实？（针对男转女Mod的秘诀）：

        胶囊体一定要比实际的大腿粗一圈！ 因为男主步子大，动画播放过快时，如果胶囊体刚刚好贴合大腿，骨骼瞬间位移可能会让裙摆“漏”进去。加粗胶囊体可以提前推开裙子。

    应用变量到节点：

        把左侧的 LegColliders 变量拖拽进 AnimGraph 中，选择 Get。

        选中所有的裙子 Kawaii 节点，在细节面板中找到 Capsule Limits。

        勾选它前面的小方块（将其暴露为输入引脚）。

        将蓝图里的 LegColliders 节点连入所有裙子 Kawaii 节点的 Capsule Limits 引脚。

第四阶段：解决极端动作的裙子翻转（走光限制）

即使有碰撞体，如果角色做空翻或极高速下坠的动作，裙子可能会直接翻到头顶下不来。Kawaii 提供了限制角度的功能。

    选中裙子的 Kawaii 节点。

    找到 Limit Angle（角度限制） 选项。

    勾选并启用它。

    Limit Angle 的值设为 45 到 60 度之间。

        原理：这会强制规定裙子骨骼相对于它原本状态的最大旋转角度。一旦裙子被腿推高超过设定角度，就会被强制压下来。

总结检查清单

当你配置完成后，点击蓝图编辑器里的 Play 或挂载到游戏里测试，检查以下几点：

    原地快速转身： 裙摆是否有跟随惯性摆动？（测试 Damping 和 Stiffness）。

    极大跨步跑（男主跑姿）： 大腿是否穿透裙摆？如果穿透，去加大 LegColliders 变量里大腿胶囊体的 Radius（半径）。

    跳跃下坠： 裙摆是否翻到头顶下不来？如果是，收紧 Limit Angle（角度限制）。

使用这套方案，裙子完全在组件空间内自我结算，不吃全局风力，不吃重力突变，非常稳定，是目前UE动作Mod圈的标准工业做法。
